# Examples

Ready-to-run setups, each in its own folder with its configs, scripts to
start it, and a README. Build first (`Build.ps1` at the root): the scripts
take the exes from `Build\`, or from a release folder with `-BinDir`.

| Example | What it shows |
|---|---|
| [`SingleServer`](SingleServer/README.md) | One server, one client: pushing, reading, attachments, names, SQL, with the tools. |

Their keys are in the repository, so public: they're only for trying the
examples locally, never reuse them.
